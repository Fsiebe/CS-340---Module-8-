1. Writing Maintainable, Readable, and Adaptable Code (CRUD Module)
To keep my code clean and easy to work with, I used clear naming, added comments, and separated logic into functions. The CRUD module from Project One made things way easier in Project Two—I didn’t have to rewrite database code for each widget. It saved time and reduced errors. I could definitely reuse it in future projects that use MongoDB or even build on it for more features.

2. Problem-Solving as a Computer Scientist
When working on the dashboard for Grazioso Salvare, I first looked at what they needed and broke it down into smaller tasks. I focused on the data they’d use most, like animal type and location, and connected it through my CRUD functions. Compared to past projects, this one felt more real and required thinking about both the backend and the user experience. Next time, I’d start with diagrams and maybe use a more agile approach.

3. What Computer Scientists Do and Why It Matters
Computer scientists solve problems using code and systems. That’s important because almost every business runs on tech. For Grazioso Salvare, my project helps them track animals faster and make decisions quicker. It basically helps them do their job better with less manual work.
